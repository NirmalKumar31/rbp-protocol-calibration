## 3. Why the reference warranty was removed

An earlier draft ended:

> ...no reference was generated by a language model.

That is a **personal factual warranty**. No test in this repository can establish it, and the
audit that raised this was right about why: verifying that a bibliography entry's metadata is
correct is a different claim from knowing how the entry was first produced.

And it is now materially harder to give, because of section 1 item 4: five entries were added on
2026-09-07 by an assistant that located them by web search and verified each field against
Crossref before writing it. They are correct and they resolve. They were not, in the ordinary
sense, generated by the author.

The current wording removes this warranty. A narrower statement that every reference was
checked by hand against its primary record should be added only if the author personally
performed or supervised that check for all 31 entries.

## 4. Current wording, for final author confirmation

> **Use of AI tools.** I used generative AI tools (Anthropic Claude and OpenAI Codex) for coding
