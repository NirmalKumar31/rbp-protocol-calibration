## 3. The one sentence that must change or be personally attested

The paragraph currently ends:

> ...no reference was generated by a language model.

That is a **personal factual warranty**. No test in this repository can establish it, and the
audit that raised this was right about why: verifying that a bibliography entry's metadata is
correct is a different claim from knowing how the entry was first produced.

And it is now materially harder to give, because of section 1 item 4: five entries were added on
2026-09-07 by an assistant that located them by web search and verified each field against
Crossref before writing it. They are correct and they resolve. They were not, in the ordinary
sense, generated by the author.

**Recommendation, which is still the author's to accept or reject:** replace it with the
narrower statement that is verifiable, namely that every reference was checked by hand against
its primary record. The eight-audit review reports that all 24 bibliography DOIs resolved and
their normalised titles matched Crossref metadata, so the narrower statement is supportable.
Keep the stronger sentence **only** if the author can personally verify it for all 31 entries.

> interpretations, manually verified the reported results and references against the
> accompanying evidence and source records, and is solely responsible for the content of this
> work. All reported values are produced by code in the accompanying repository and are checked
> against committed evidence by its verification harness.

**Three choices inside that draft, all the author's:**

**(a) The bracketed clause.** Include it and name the audit systems, or drop the bracket and
keep the more general "including Anthropic Claude ... and for audits", which discloses that
audit assistance happened without naming who. The second is honest and shorter. The first is
more complete. Either is defensible; only the author can pick.

**(b) The reference sentence.** The draft above uses "manually verified the reported results and
references against the accompanying evidence and source records" and **drops** "no reference was
generated by a language model". If the author wants the stronger sentence back, it must be
verified by hand first, for all 31 entries.

**(c) Whether to name the audit findings at all.** The draft points at
`docs/AUDIT-RESPONSE.md`. That is unusually transparent and it is a choice, not a requirement.

**No AI system is presented as an author** in this draft or anywhere in `CITATION.cff`, and that
should not change.
